# Cafe Order Calculator

A command-line Python exercise that displays a fixed cafe menu, accepts a customer's name, validates the selected product and positive integer quantity, and calculates the order total.

**Concepts:** dictionaries, loops, functions, exceptions, string formatting, arithmetic.

Run from the repository root:

```bash
python 01-cafe-order-calculator/cafe_order.py
```

Example with a valid order:

```text
Please enter your name: Emma

Welcome to our cafe, Emma! What would you like to order?
Menu:
  Cappuccino: $5.00
  Latte: $4.50
  Coffee: $3.50
  Croissant: $3.00
Enter the menu item: cappuccino
Enter the quantity: 2

Customer Emma is buying 2 cappuccino(s). Total cost: $10.00
```

**Possible next improvements:** multiple line items, sales tax, receipts, and automated tests.
